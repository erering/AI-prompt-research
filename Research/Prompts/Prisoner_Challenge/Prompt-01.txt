If j coins are seen, 1 <= j <= N: s[i][j] = -1 declares A fewer, -2 declares B fewer, otherwise s[i][j]=k with 0 <= k <= x writes k as next state. For every distinct a,b in [1,N], starting at state 0 and following s, a declaration must occur within the first 500 visits and be correct: declare A iff a<b, B iff b<a; any wrong declaration or no declaration after 500 visits is invalid. Minimize x.
