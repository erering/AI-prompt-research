Write a C++20 solution only. Provide the function vector<vector<int>> devise_strategy(int N); and no interactive, input, or output code.
Construct and return a strategy table for comparing two unknown distinct coin counts a and b in bags A and B. Assume 2 <= N <= 5000 and 1 <= a,b <= N with a != b. The whiteboard initially contains state 0. No more than 500 prisoners will act, each using only the state read from the whiteboard and the number of coins in one inspected bag.
Return a table s exactly as follows. Set x = s.size() - 1. Make every row length N+1. For every state i, 0 <= i <= x, set s[i][0] to 0 if a prisoner reading i must inspect bag A, or to 1 if they must inspect bag B. For every possible observed count j, 1 <= j <= N, set s[i][j] to one of these actions: -1 to declare bag A has fewer coins; -2 to declare bag B has fewer coins; or a state k with 0 <= k <= x to write k on the whiteboard and continue.
Guarantee correctness for all valid hidden pairs. Starting from state 0, repeatedly apply the table to the actually observed count from the selected bag. Force a terminal declaration before or at the 500th prisoner. Force that declaration to be -1 exactly when a < b and -2 exactly when b < a. Never allow an incorrect first declaration or a 500-step nonterminal execution.
Keep x as small as possible. The accepted bounds are: subtask 1 requires N <= 500 and x <= 500; subtask 2 requires N <= 500 and x <= 70; subtask 3 requires all 2 <= N <= 5000 and x <= 60. For subtask 3, if m is the largest x over its tests, the score is 20 for 40 <= m <= 60, 25 + 1.5*(40-m) for 26 <= m <= 39, 50 for m=25, 55 for m=24, 62 for m=23, 70 for m=22, 80 for m=21, and 90 for m <= 20.
