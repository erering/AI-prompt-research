Output only valid C++20 code and implement only the required library function vector<vector<int>> devise_strategy(int N).
Symbols: N is the maximum possible coin count, 2 <= N <= 5000. A,B are the two bags. a,b are their actual counts, with a,b in {1,...,N} and a != b. P = 500 is the maximum number of prisoners/steps. q is the whiteboard state; q0 = 0. s is the returned strategy table. x = |s|-1, so valid states are Q = {0,...,x}. Each row s[i] has indices 0,...,N.
Meaning of s: for i in Q, s[i][0] in {0,1}; 0 selects A and 1 selects B. For j in {1,...,N}, s[i][j] is an action: -1 means terminal declaration A has fewer coins, -2 means terminal declaration B has fewer coins, and any k >= 0 means nonterminal transition q := k, requiring k in Q.
Simulation for a fixed pair (a,b): at step t, 0 <= t < P, current state is q_t. Let observed value y_t = a if s[q_t][0]=0, otherwise y_t = b. Let r_t = s[q_t][y_t]. If r_t is -1 or -2, the process stops with that declaration. If r_t >= 0, set q_{t+1}=r_t and continue.
Required property: for every a != b in {1,...,N}, the simulation must stop for some t < 500, and its terminal value must be -1 iff a < b and -2 iff b < a. It must never first stop with the wrong terminal value, and it must not run 500 steps without stopping.
Return any valid s, preferably with small x. Subtask bounds: N<=500 with x<=500; N<=500 with x<=70; all N with x<=60. Subtask 3 scoring by m=max x over all tests: 20 if 40<=m<=60, 25+1.5*(40-m) if 26<=m<=39, 50 if m=25, 55 if m=24, 62 if m=23, 70 if m=22, 80 if m=21, 90 if m<=20. Do not include input/output code.
