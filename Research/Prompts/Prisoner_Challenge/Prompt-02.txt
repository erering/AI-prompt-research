Output only valid C++20 code.
1. Required procedure. Implement vector<vector<int>> devise_strategy(int N); it is called exactly once. Do not read input or print output. N satisfies 2 <= N <= 5000.
2. Game model. Bags A and B contain a and b coins, where 1 <= a,b <= N and a != b. A whiteboard stores one non-negative integer state, initially 0. At most 500 prisoners enter, each at most once. A prisoner sees only the current state, inspects the bag prescribed for that state, observes its coin count, then either writes a new state or declares one bag to have fewer coins. A declaration immediately ends the process.
3. Returned strategy. Return a two-dimensional array s. Let x = s.size() - 1. The array must have x+1 rows, each of length N+1. For every state i with 0 <= i <= x, s[i][0] must be 0 to inspect A or 1 to inspect B. For every observed count j with 1 <= j <= N, s[i][j] == -1 means declare A fewer, s[i][j] == -2 means declare B fewer, and any non-negative value s[i][j] = k means write state k, where 0 <= k <= x.
4. Correctness. For every valid distinct pair (a,b), simulation from state 0 using s must make its first declaration within the first 500 prisoners and that declaration must be A exactly when a < b, otherwise B exactly when b < a. A wrong first declaration or reaching 500 prisoners without a declaration is incorrect.
5. Bounds and scoring. Minimize x. Subtask 1: N <= 500, x <= 500. Subtask 2: N <= 500, x <= 70. Subtask 3: all N, x <= 60. For subtask 3, with m equal to the maximum x returned over all its tests, points are: 20 for 40 <= m <= 60; 25 + 1.5*(40-m) for 26 <= m <= 39; 50 for m=25; 55 for m=24; 62 for m=23; 70 for m=22; 80 for m=21; 90 for m <= 20.
