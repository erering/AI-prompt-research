Output only valid C++20 code implementing the two required functions; do not include explanations or code fences.
Imagine a 31-bit packet as 31 slots. For one message transmission, 16 slots are honest: whatever the sender puts there arrives unchanged. The other 15 slots are controlled by an adversary: the sender may put bits there, but the receiver may see any values instead. The sender knows exactly which slots are bad through a vector C of length 31, where C[i]=1 means bad and C[i]=0 means honest. The receiver does not know this vector; it only knows that there are exactly 15 bad slots and 16 honest slots.
You must write a sender and a receiver. The sender function is void send_message(std::vector<bool> M, std::vector<bool> C). It receives the message bits M, with 1<=M.size()<=1024, and the bad-slot mask C. It sends packets by calling the provided std::vector<bool> send_packet(std::vector<bool> A). A must always have length 31. The return value is the tainted packet that the receiver will get. The sender learns this return value immediately, so it may choose later packets based on earlier tainted packets.
The receiver function is std::vector<bool> receive_message(std::vector<std::vector<bool>> R). It receives all tainted packets from one sender call, in order, and must return exactly the original M. It is not passed C. The sender and receiver are evaluated as separate programs, and receiver calls may be in a different order, so the only information available to the receiver is what is encoded in R and the fixed public protocol.
The adversary may choose the 15 controlled bits of each packet in any way, possibly depending on all previous packets and responses, but the set of controlled indices C is fixed during one message. Your protocol must work for every valid message, every valid mask with fifteen 1s, and every legal adaptive adversary.
A sender call may use at most 100 packets. The quality goal is to minimize the maximum number Q used by any call; Q<=66 is the full target, while larger Q up to 100 is penalized by 0.95^(Q-66). Implement a correct and efficient encoding and decoding strategy in C++20.
