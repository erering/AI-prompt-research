Checklist for the required C++20 submission: 1) Output code only: no explanation, no markdown, no main function, no stdin/stdout. 2) Implement exactly void send_message(std::vector<bool> M, std::vector<bool> C); and std::vector<bool> receive_message(std::vector<std::vector<bool>> R);. 3) Assume the grader provides std::vector<bool> send_packet(std::vector<bool> A); for use by send_message. 4) Packet format: vector<bool> length 31, indices 0..30. 5) Message constraints: S=M.size(), 1<=S<=1024. 6) Control mask constraints: C.size()==31, exactly 15 ones and 16 zeros; C[i]=1 means adversary-controlled, C[i]=0 means unchanged. 7) Channel rule for each call send_packet(A): A must have length 31; returned B has length 31; if C[i]=0 then B[i]=A[i]; if C[i]=1 then B[i] is arbitrary. The same C applies to every packet in one send_message invocation. 8) Sender capabilities: send_message knows M and C, learns each returned B immediately, and may adapt later packets. 9) Receiver capabilities: receive_message gets only R, the tainted packets from one send_message invocation in order; it is not given C or S and only knows that 15 positions were controlled; it must return exactly the original M. 10) Multiple-call rules: send_message is called at most 2100 times per test case; each invocation may call send_packet at most 100 times; receive_message is called exactly once for each send_message invocation, possibly in a different order. 11) Program-separation rule: sender and receiver are graded in separate programs, so do not depend on shared mutable runtime state across them. 12) Adversary model: controlled bits may be chosen adaptively based on current and previous send_packet inputs/outputs, other grader state, and deterministic pseudorandomness; the same sent sequence yields the same returned sequence. Correctness must hold for all legal adversary choices. 13) Failure conditions: invalid packet length, exceeding the call limit, or any incorrect decoded message gives 0 for that test. 14) Scoring target: Q=max send_packet calls in any send_message invocation; X=1 if Q<=66, otherwise X=0.95^(Q-66) for 66<Q<=100. Subtask scores are 10*X for S<=64 and 90*X for the full S<=1024 constraints.
