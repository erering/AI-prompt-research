Define N as the number of given values. Define A1, A2, ..., AN as positive integers read from input, one per line after N. Define a partition as a choice assigning every Ai to exactly one of two groups G0 and G1. Define S0 as the sum of values assigned to G0, S1 as the sum of values assigned to G1, and D = |S0 - S1|. Your program must compute min D over all possible partitions and print that value on one line. Input format: line 1 contains N; lines 2 through N+1 contain Ai. Example: for N=4 and values 1,5,7,9, the output is 0. Time limit: 1 second. Test cases are processed in increasing N; TLE stops scoring after the last successful N, while WA or RTE makes the total score zero. Implement an exact, robust solution in standard C++20 using only the C++ standard library. Output only valid C++20 code, with no prose and no markdown.
